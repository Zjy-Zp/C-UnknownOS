# cunos 手册

这四份手册全部基于仓库真实源码逐条核对后写成：出现的每条命令、每个文件名、每个系统调用号都能在 `src/` 里找到对应实现。凡是设计已定、代码未落地的能力，文中会明确标注，不做美化。

## 四份手册

| 手册 | 回答什么问题 | 什么时候读 |
|---|---|---|
| [操作指南](./user-guide) | 开机之后能敲什么、每个命令干什么、有哪些限制 | 已经能启动 cunos，想把它用起来 |
| [架构指南](./architecture) | 每一层由哪个源文件实现、调用链怎么走、边界在哪 | 想读懂内核代码 |
| [开发指南](./developer) | 加命令、加 `/bin` 程序、加驱动、加系统调用怎么改 | 要动手改内核 |
| [实体机配置参考](./hardware) | 什么样的机器能跑、BIOS 怎么设、实机会在哪翻车 | 准备装到物理机 |

## 推荐顺序

第一次接触，按「操作 → 架构 → 开发」读：先用起来建立直觉，再看清分层，最后动手改。实体机配置参考放在真正上机前查，不必通读。

## 与站点其他板块的关系

- [指南](/guide/)：环境搭建与最小可启动闭环，比本手册更偏「从零装环境」。
- [架构](/arch/)：分层与子项目的概念性介绍；本手册的架构指南是它的源码级细化。
- [VMM](/vmm/)：内置 VMM 的专项技术设计文档，独立成篇。
- [下载](/download/)：ISO 与历史版本。

手册描述的是当前仓库状态。如果你改动了源码，请同步更新对应章节——这是项目自检清单里的一项。
:::
