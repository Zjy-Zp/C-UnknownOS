# cunos 内置 VMM 技术设计文档

本系列文档描述在 cunos 自研 32 位 i386 保护模式内核内，实现一个基于 AMD SVM（AMD-V）的 Type-1 形态虚拟机监视器的完整设计。

目标是在不引入任何 Linux 代码的前提下，把真实的 Debian i386 用户态跑起来。

- **版本**：v0.1（设计稿，未实现）
- **适用代码基线**：cunos v1.1（`C:\cunos\src`，含 `paging.c` / `mm.c` / `proc.c` / `vfs.c` / `ext2.c` / `ata.c` / `ahci.c` / `pci.c`）
- **约定**：凡标注 **【需核对】** 的硬件数值，落地前必须以 AMD APM Vol.2 Appendix B（VMCB 布局）与 Appendix C（退出码）逐条比对，并在代码里用 `offsetof` 静态断言，把"文档可能写错"转成"编译期必失败"。
